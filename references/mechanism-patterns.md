# 从原理选择动态表达

先回答：观众需要理解的是物质/能量/信息如何移动，还是对象如何变形、反应、切换状态？以下是选择规则，不是必须套用的外观模板。

| 主导关系 | 画面与动作 | 必须保持的语义 | 常见失误 |
| --- | --- | --- | --- |
| 输运、传热、扩散、电流 | 剖面、分区、场或独立运动通道；用颜色、路径区分载体 | 通道边界、方向、驱动力；物质流和能量流分别定义 | 把电流方向当电子方向；把扩散画成整齐单向输运；粒子穿壁 |
| 化学反应、结合、催化、生物作用 | 实体接近、结合态停留、解离或产物分离；键/位点采用局部特写 | 实体身份、反应先后、计量关系；假设途径明确区分 | 用碰撞自动暗示反应；凭空增加分子；把示意尺寸当真实比例 |
| 反馈、调控、控制系统 | 信号、作用对象、观测/反馈路径分区；节点状态跟随消息变化 | 正负作用符号、延迟、输入输出与闭环方向 | 只让箭头流动却没有状态变化；把反馈方向画反 |
| 算法、协议、逻辑过程 | 状态节点、数据对象和条件高亮；同一对象跨步骤保持颜色/编号 | 分支条件、并发/串行、终止条件、状态与数据区别 | 每步都复制数据形成假象；暗示所有分支都会执行 |
| 振动、波、光学、电磁 | 时间驱动的相位、波形或几何变换；必要时叠加幅度/时间轴 | 横纵波区别、参考系、传播与振动的区别 | 用静态曲线平移替代错误物理含义；伪造测量波形 |
| 力学、运动机构、变形 | 固定锚点、关节和连杆；必要时使用投影、局部放大或多视图 | 约束、接触、方向、参考系；几何不能相互穿透 | 所有构件独立动，破坏机械约束；曲率/接缝跳变 |
| 多尺度或复杂耦合 | 总览与局部放大分镜，维持同一视觉标识；一次解释一个关系 | 比例变化、时间尺度变化与局部假设要标明 | 同屏堆积全部信息，文字变小；暗示跨尺度同步 |

跨领域沿用的是“证据 → 视觉模型 → 几何 → 运动 → 验收”，不是热管形状。

## 分镜记录的最小内容

用自然语言或表格记录每个时段的原因、动作、结果、对应来源。标出哪些动作同时发生、哪些只是为了讲解而分开展示。示意与定量数据分开；提供真实数据时使用单位、轴、比例和来源，不能只把数据变成装饰运动。

复杂对象可用两到三个连续镜头：结构建立 → 关键局部机制 → 回到整体结果。使用同一 JSON 的透明度/位置轨道组织场景，保持每一阶段都可暂停阅读。不要制造对实际对象没有意义的爆炸图、粒子闪光或旋转镜头。

## 使用示例的边界

- `examples/heat-pipe`：同心剖面、曲边纹理、裁切、分离的运动路径与外部标注。
- `examples/state-transfer`：抽象状态转换，表现“触发条件满足才进入下一状态”，避免依赖热管几何。
- `examples/reversible-binding`：抽象 A+B ⇌ AB 教学模型，表现实体合并与分离、前后关系；不是具体分子的真实反应途径。

后两例的规则在分镜中完整定义，用来验证不同表达方式与播放器。应用到实际算法、生物或化学问题时应替换为用户资料支持的状态/反应，不能把示例当文献依据。
